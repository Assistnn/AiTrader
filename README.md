# AI Trading System

FX（GMOコイン）と暗号通貨（bitbank）に対応した自動取引システムです。

## 設計思想

このシステムは以下の優先順位で設計されています。

1. **生存性** — 利益最大化ではなく破綻回避を最上位目的とする
2. **透明性** — 「なぜこの判断になったか」を追跡できる
3. **デバッグ容易性** — 問題発生時に原因箇所を素早く特定できる
4. **チューニング支援** — パラメータ調整の効果を比較検証できる

## 4段階判断パイプライン

このシステムの中核は、4段階の判断プロセスです。

```
M1（方向判定）  → 今日の相場は上か下か？
M2（セットアップ）→ エントリーの条件は整っているか？
M3（エントリー）  → 今このタイミングで注文するか？
M4（退出管理）   → ポジションをいつ閉じるか？
```

各段階で3つのモードを選択できます。

- **rule** — プログラムが機械的に判断（完全自動、AI不使用）
- **aiAssist** — プログラムが判断し、AIが補助的に意見を出す
- **aiFull** — AIが主体的に判断する

# 01. 画面仕様書

## 1. 概要

Figma UI仕様とExcel仕様を統合した全画面仕様を定義する。

**UI方針（確定）:**
- Figma画面はオーナー側で更新しない
- 現在のFigma画面を基本再現し、仕様不整合は開発側で画面を調整
- 画面の具体的な修正は実装フェーズで行う

## 3. 画面詳細

### 3-1. ダッシュボード

**構成:**
```
+------------------------------------------+
| ヘッダー（ロゴ、ユーザー、設定リンク）     |
+------------------------------------------+
| マーケットウォッチ      | チャートパネル    |
| (左パネル)              | (中央パネル)      |
|  - 通貨ペアリスト       |  - OHLC          |
|  - Bid/Ask/スプレッド   |  - 指標オーバーレイ|
|                         |  - 時間足切替      |
+-------------------------+-----------------+
| トレーダーパネル（下部）                   |
|  - トレーダーカード x N                    |
|    [名前][状態][損益][ポジション]           |
|    [パイプライン状態][ガード状態]    ← 追加 |
+------------------------------------------+
```

**追加要素（Figmaにないもの）:**
- トレーダーカードに「パイプライン状態」をコンパクト表示
  - 最新M1判定: UP/DOWN/NEUTRAL アイコン
  - ガード状態: 正常(緑)/警告(黄)/停止(赤) インジケータ
- チャートの時間足にM30を追加（Excel仕様）
- チャートの指標プリセット（M1用: EMA+ADX, M2用: RSI+BB等）

### 3-2. トレーダー設定画面

**Figmaからの変更（再設計レベル）:**

```
2カラム・900px幅は踏襲。右ペインをタブ構造に変更。

左ペイン: トレーダーリスト（Figma通り）

右ペイン:
  [基本情報] [M1-M2] [M3-M4] [MX]  ← タブ

  Tab: 基本情報（T-001〜T-012）
    - トレーダー名
    - 取引タイプ（FX/Crypto）
    - 通貨ペア選択
    - 資金枠
    - 注文数量単位
    - 戦略テキスト
    - 通知設定（6項目）

  Tab: M1-M2
    M1 方向・レジーム判定（11項目）
      - 有効化
      - 時間足選択
      - トレンド判定ON/OFF
      - レンジ回避ON/OFF
      - ボラティリティ判定ON/OFF
      - AI使用方式（rule/aiAssist/aiFull）
      - AIプロバイダー/モデル/信頼度閾値
    M2 セットアップ判定（8項目）
      - 有効化
      - 時間足選択
      - 戦略プリセット
      - Advanced設定
      - AI使用方式
      - 確率しきい値

  Tab: M3-M4
    M3 エントリー（8項目）
      - 有効化
      - 時間足選択
      - エントリー方式（market/limit）
      - TP/SL方式（fixedPips/atr）
      - 1回あたりリスク%
      - 実行前チェック
      - AI使用方式
    M4 退出管理（9項目）
      - 有効化
      - 管理方式
      - ブレイクイーブンON/OFF
      - トレーリングストップON/OFF
      - 部分利確ON/OFF
      - 最大保有時間ON/OFF
      - AI許可操作

  Tab: MX 統合判定（5項目）
    - 判定方式（all/dir+setup/score）
    - スコア重み（方向/セットアップ/実行）
    - スコアしきい値
```

### 3-3. 取引履歴画面

**追加要素:**
- テーブル行クリックで展開パネル表示
- 展開パネル: 4段階判定結果（M1〜M4のoutput_snapshot）
- 展開パネル: セーフガード評価結果
- CSVエクスポートボタン

### 3-4. 通知設定画面

**追加要素:**
- トリガー種別にセーフガード発動、パイプラインアラートを追加

### 3-5. システム設定画面

**追加メニュー項目:**
```
既存:
  - 取引所API設定
  - AI API設定
  - アカウント設定

追加:
  - セーフガード設定（SG-001〜SG-040）
    ※ 未確定事項: トレーダー設定内 or システム設定内 or 混合
  - コスト管理（レートリミット、予算設定、使用量表示）
  - 経済指標カレンダー（データソース設定）
```

### 3-6. バックテスト画面（新規）

```
構成:
  左: バックテスト実行設定
    - トレーダー選択
    - 通貨ペア
    - 期間（開始/終了）
    - 「現在の設定で実行」ボタン
  右: 結果表示
    - 評価指標サマリ（勝率、PF、最大DD、シャープレシオ等）
    - 資産曲線チャート
    - トレードリスト（テーブル）
    - 実行履歴一覧
```

### 3-7. パイプラインログ画面（新規）

```
構成:
  上: フィルタバー
    - トレーダー、通貨ペア、段階、日付範囲
  下: ログテーブル
    - execution_id, timestamp, stage, mode, 判定結果サマリ
    - 行クリックで詳細展開（input/output/config JSON）
```

### 3-8. 設定変更履歴画面（新規）

```
構成:
  フィルタ: トレーダー、設定種別、日付範囲
  テーブル: 変更日時、変更者、段階、変更理由
  詳細: before/after のJSON diff表示
```
